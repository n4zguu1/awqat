# Notifications

## Goal

Notify users about configured prayer times without requiring the terminal
screen to remain focused.

## Requirements

- Allow notifications to be enabled or disabled globally.
- Allow individual prayer notifications to be configured.
- Allow a notification lead time or interval.
- Report unsupported platform notification behavior.

## Open questions

- Which notification systems are supported on Linux and Windows?
- Should notifications require a running background process?
- How should notification failures be surfaced?

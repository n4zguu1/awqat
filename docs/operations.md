# Operations

This document describes how maintainers build, test, package, and release
Awqat.

## Local development

Run the project using the commands defined by the repository's Rust tooling.
Keep platform-specific setup instructions here as they become established.

## Release checklist

- Run formatting, linting, and tests.
- Verify Linux and Windows build requirements.
- Verify configuration migration behavior.
- Update the changelog and version.
- Test the packaged binary on supported platforms.

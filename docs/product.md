# Awqat

Awqat is a cross-platform terminal application for viewing Islamic prayer
times, Gregorian and Hijri dates, and related daily information.

## Primary user

A person who wants prayer times in a terminal without depending on a browser
or graphical desktop application.

## Initial platforms

- Linux terminals
- Windows terminals

## Product principles

- Correctness is more important than visual novelty.
- Calculations and data sources must be explainable.
- Offline use should work after setup.
- Configuration must be recoverable and editable.
- The application must fail visibly when data is uncertain.

# Configuration

## Goal

Persist the user's choices so the application can reopen without repeating the
initial setup.

## Requirements

- Persist the selected city and timezone.
- Persist the selected calculation method and madhab.
- Persist the high-latitude rule and prayer-time adjustments.
- Persist the Hijri date correction.
- Persist display preferences, including language, theme, and time format.
- Persist notification settings.

Configuration must be recoverable and remain valid when optional settings are
missing or have not yet been configured.

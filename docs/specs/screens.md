# Screens

## Setup screen

- Input controls for location data.
- A results table showing matching cities as the user types.

## Error screen

- Display errors such as a missing location, an unavailable configuration file,
  or another recoverable application failure.

## Table view screen

- A scrollable table showing prayer times for a wider date range.
- Lazy loading may be used if the date range becomes large.

## Settings screens

- Allow the user to change language, location, madhab, calculation method, and
  notification-related prayer-time adjustments.

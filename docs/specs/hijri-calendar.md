# Hijri calendar

## Goal

Display a useful Hijri date while making the calculation method and
uncertainty clear to users.

## Requirements

- Provide an offline default.
- Allow a user-applied date correction.
- Persist the correction across restarts.
- Explain that calculated dates may differ from local moon-sighting decisions.

## Open questions

- Which online sources, if any, should be supported?
- Should correction be global, country-specific, or city-specific?
- How should automatic updates be scheduled?

# ADR 0003: City data source

- Status: Proposed
- Date: 2026-10-06

## Context

Awqat should support many cities without hardcoding an unmaintainable list.
Cities can have duplicate names, changing boundaries, and different timezones.

## Decision

To be decided after evaluating the available datasets, licensing, update
process, coordinate accuracy, and offline distribution size.

## Evaluation criteria

- Clear redistribution license.
- Stable identifiers for cities.
- Coordinates and IANA timezone data.
- Region and country relationships.
- Deduplication and search quality.
- Reproducible dataset updates.
